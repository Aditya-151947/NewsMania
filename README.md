# 📰 NewsMania

**NewsMania** is a responsive and user-friendly React application that delivers the latest news across various categories. Built with modern UI/UX principles and scalable component architecture, it offers a smooth browsing experience for news enthusiasts.

---

## 🚀 Features

- 🔍 Browse news by category (e.g., Technology, Sports, Business)
- 🌐 Fetches real-time data from a news API
- 📱 Responsive design for mobile and desktop
- 🧩 Modular components for scalability
- 🖼️ Fallback images for missing thumbnails
- 🎨 Clean UI with Bootstrap styling
- 🧠 Error handling and loading states

---

## 🛠️ Tech Stack

- **React** (with JSX)
- **Vite** (for fast bundling)
- **Bootstrap** (for styling)
